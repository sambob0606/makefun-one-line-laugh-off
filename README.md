A Python program that writes one original funny line about agent-builder life for [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) on make.fun.

The line:

> I asked my agent to do my job for a day — it finished by 9:04, then spent the rest of the day writing my performance review.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
